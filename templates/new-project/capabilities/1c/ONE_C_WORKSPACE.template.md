# Рабочая область 1С: <PROJECT_NAME>

Общая область для всех баз этого проекта. Реестр баз — `config/1c-projects.tsv`,
назначение контуров — `docs/operations/ENVIRONMENT_REGISTRY.md`, инструменты —
`docs/operations/TOOLCHAIN.md`.

## Базы

Одна строка на пару «база + контур». Реестр ведёт `add-1c-base` в
`config/1c-projects.tsv`; этот обзор человек поддерживает сам, скилл его не
трогает. Вручную сюда
дописывают только пояснения, которых нет в реестре.

## Соглашения

- Исходники хранятся в EDT-формате; XML-инструменты работают через конвертацию.
- Доработка делается расширением, если база не снята с поддержки явно.
- Реальные строки соединения, пароли и токены в Git не попадают.
