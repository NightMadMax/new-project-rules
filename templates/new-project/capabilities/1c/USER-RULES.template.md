# Правила проекта <PROJECT_NAME>

Постоянные правила именно этого проекта: соглашения разработки конфигурации,
ограничения на изменение типовой, именование, обязательные проверки. Файл
принадлежит команде — стандарт его не перезаписывает.

Правила отсюда уточняют обычные правила 1С, но не отменяют системные
ограничения, безопасность, запрет секретов и общие правила репозитория.

Сюда не пишут: параметры баз и порты (они в реестре и локальных файлах),
конфигурацию MCP, секреты, временные договорённости и выведенные автоматически
правила поведения агента.
