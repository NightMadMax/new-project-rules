# Регистрация базы в реестре

Реестр — источник истины о том, какие базы существуют для skills. Пока строки
нет, базы для агента нет.

Скрипты стандарта живут в чекауте `new-project-rules`, а не в проекте, и путь к
нему в проекте не записан. Первый шаг — спросить у пользователя путь к чекауту.
Команды ниже выполняются оттуда, `--root` указывает на проект.

## Порядок

1. Спросить и записать: `project_id`, `environment_id`, папку исходников,
   конфигурацию, версию платформы, режим совместимости, `application_kind`,
   режим поддержки, формат исходников, EDT-workspace и профиль, владельца.
2. Признак `is_production` называет пользователь. Значение по умолчанию —
   `false`; «наверное, тестовая» не подходит.
3. Канал выдаётся только базе с `mcp_enabled = true`, 1–64 символов `a-zA-Z0-9_-`,
   и только свободный. Совпадение каналов означает, что операция уйдёт не в ту
   базу, поэтому занятый канал — отказ, а не предупреждение.
4. Записать строку и проверить:
   `./scripts/validate-project.sh --root <проект> --report-only` — раздел
   `registry.*` должен быть пуст.
5. Создать карточку базы: скопировать `configurations/PROJECT_1C.template.md`
   в `configurations/<base>/PROJECT_1C.md` и заполнить. Обязательное поле —
   **версия БСП**: реестр её не хранит, потому что она меняется вместе с
   обновлением типовой и нужна человеку и агенту при выборе API, а не машинной
   проверке. «Не выяснено» — допустимый ответ, пустое поле — нет.
6. Дописать базу в таблицу «Базы» файла `ONE_C_WORKSPACE.md`: этот документ
   заявляет, что его ведёт `add-1c-base`, и без этого шага заявление ложно.
7. Обновить `docs/operations/ENVIRONMENT_REGISTRY.md`: назначение контура,
   какие в нём данные, кто делает резервную копию и как восстанавливают.
   Реестр хранит машинные признаки, документ — человеческую политику.
8. Пересобрать клиентские проекции: `activate-1c-client`.

## Границы

- Машинные пути в реестр не пишутся: он общий для всех участников.
- Создание самой информационной базы сюда не входит — это операция над данными
  машины и выполняется отдельно, с подтверждением.
