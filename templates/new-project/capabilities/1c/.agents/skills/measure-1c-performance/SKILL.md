# Замеры производительности

Замер меняет состояние базы: документы проводятся, регистры пишутся. Поэтому
предусловий больше, чем у чтения.

## Предусловия

1. Действующий session lock от `select-1c-project`.
2. Контур не production. Замер на production не выполняется.
3. **Подтверждённая свежая резервная копия выбранной базы.** Backup живёт вне
   git и вне видимости агента, поэтому здесь достаточно явного ответа
   пользователя — но без него работа не начинается.
4. Назначение контура прочитано в `docs/operations/ENVIRONMENT_REGISTRY.md`:
   на контуре с боевыми данными замер согласуется отдельно.
5. Подтверждённый режим записи: на обычном приложении запущена write-enabled
   сборка, на управляемом — включённый переключатель записи подтверждён
   вызовом.
6. Названы preflight и план отката: что проверяется до запуска и как
   возвращается состояние, если результат окажется неприемлемым. «Откатимся из
   резервной копии» — это план только тогда, когда названо, кто и как его
   выполняет.

## Server-vs-client guard (только `application_kind = ordinary`)

В сборке обычного приложения директивы управляемых форм не сохраняются, поэтому
серверный `execute_code` может исполниться на клиенте: цифры получатся
клиентские, а модальный диалог в автоматическом режиме никто не закроет и вызов
провисит до таймаута.

Проверка: до замеров и проведений выполнить пробу, возвращающую собственный
контекст исполнения (`#Если Сервер Тогда` / `#Иначе`). Продолжать только при
ответе «сервер». Отсутствие пробы — невыполненный гейт, а не «вероятно, всё
хорошо». На управляемом приложении проверка не применяется.

## No-blind-retry

После HTTP-таймаута пакетного `execute_code` результат потерян, но серверный BSL
мог не остановиться. Пакет не повторяется, пока не подтверждено завершение
серверной работы. Тяжёлые типы документов — по одному документу на вызов.

## Результат

Цифры с условиями: база, контур, объём выборки, `application_kind`,
подтверждённый контекст исполнения, что именно проводилось. Замер без условий
не является результатом.
