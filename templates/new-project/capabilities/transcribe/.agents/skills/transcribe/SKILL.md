# Расшифровка записи

Распознавание выполняется **на этой машине**. Исходное аудио или видео никуда
не загружается: обычная расшифровка не требует ни ключа API, ни поминутной
оплаты, ни отправки чужой встречи наружу.

## Порядок

1. Проверить зависимости. Skill их не устанавливает: `faster-whisper` —
   условная зависимость, ставится в project-local окружение и только с
   разрешения пользователя. Первая загрузка модели — это загрузка модели, а не
   отправка записи; сказать об этом отдельно.
2. Расшифровать:

   ```sh
   python3 .agents/skills/transcribe/scripts/transcribe.py <файл> --output-dir .
   ```

3. Показать результат и то, что не получилось. Пустая расшифровка результатом
   не считается: файл без сегментов — это тишина, повреждённый файл или
   несостоявшееся декодирование, и скрипт останавливается с названной причиной.
4. Для протокола встречи (`--with-summary`) summary пишет текущий AI-клиент по
   **готовому transcript**. Исходное медиа ему не передаётся.
5. Для разбора интерфейса (`--analyze-ui`) кадры извлекаются локально, а затем
   transcript и кадры анализирует текущий multimodal-клиент. Перед передачей
   изображений сказать пользователю, что это внешняя обработка.

## Результаты

```text
Transcript/<имя>/
├── <имя> - transcript.md   ← пишет скрипт
├── <имя> - summary.md      ← пишет AI-клиент по готовому transcript
├── <имя> - detailed.md     ← пишет AI-клиент по готовому transcript
└── screenshots/            ← кадры, только с `--analyze-ui`
```

Скрипт пишет **один** файл — transcript. Summary и detailed создаёт текущий
AI-клиент из готовой расшифровки: у скрипта нет суммаризатора, и обещать его
результат означало бы ждать файла, которого никто не напишет.

Расширение следует выбранному `--format`: `transcript.md`, `transcript.txt` или
`transcript.json`. JSON в файле с расширением `.md` не открывается корректно ни
одним инструментом.

Имена канонические и одинаковые во всех режимах. Второго набора имён нет:
расхождение документации и скрипта означало, что результат нельзя найти
надёжно.

## Границы

- Медиа не уходит во внешний сервис ни в одном режиме по умолчанию.
- Speaker labels не выдумываются: надёжной диаризации у базового backend нет,
  и «Спикер 1» без неё — это догадка в документе, который будут цитировать.
- Расшифровка — не протокол: факты, решения и договорённости проверяет человек.
- Transcript появляется целиком и только после успешного прогона. Половина
  результата с правильным именем неотличима от целого.
